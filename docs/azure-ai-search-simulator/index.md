# Azure AI Search Simulator

Azure AI Search Simulator is a local, API-compatible environment for developing and testing applications that use Azure AI Search. It supports familiar SDK and REST workflows without requiring a cloud service for every development iteration.

## Where to start

- [Get started](getting-started.md) with the simulator locally.
- Review the [source code and current capabilities](https://github.com/Ellerbach/azure-ai-search-simulator).
- Use the repository issue tracker for bugs and feature requests.

> [!NOTE]
> The simulator is intended for local development and testing. Validate production behavior against Azure AI Search.
