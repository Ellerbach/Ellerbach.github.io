# DocFX Companion Tools

DocFX Companion Tools is a collection of utilities, templates, tips, and workflows designed to make DocFX sites easier to generate and maintain.

## Where to start

- [Choose a tool](tools.md) for your documentation workflow.
- Read the [repository documentation](https://github.com/Ellerbach/docfx-companion-tools).
- Install the tools from the distribution channel documented by each utility.

The tools are independent, so you can adopt only the pieces your documentation pipeline needs.
