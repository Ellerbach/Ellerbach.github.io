# Tools

The project includes command-line utilities for common documentation tasks.

| Tool | Purpose |
| --- | --- |
| DocAssembler | Assemble documentation and assets from multiple locations while updating links. |
| DocFxTocGenerator | Generate and maintain DocFX table-of-contents files. |
| DocFxOpenApi | Generate DocFX-ready API content from OpenAPI descriptions. |
| DocLanguageTranslator | Support documentation translation workflows. |

See the [DocFX Companion Tools repository](https://github.com/Ellerbach/docfx-companion-tools) for the current tool list, installation commands, and detailed options.
